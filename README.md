# Atticus' Neovim Configuration
## Installation
> [!CAUTION]
> If you have a Neovim configuration already, I highly reccomend making a backup of your `nvim` folder now.

### Linux
`git clone https://github.com/AtticusHelvig/nvim-config.git ~/.config/nvim`

### Windows
`git clone https://github.com/AtticusHelvig/nvim-config.git %USERPROFILE%\AppData\Local\nvim`
